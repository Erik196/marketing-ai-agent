# Campaign review procedure

When reviewing or improving a campaign:

1. Retrieve relevant product facts and brand guidance when available.
2. Analyze the supplied CSV before recommending a channel or changing content.
3. Name the metric supporting each recommendation and acknowledge data limitations.
4. Draft only the requested assets using the evidence and brand guidance.
5. State assumptions, cite sources, and preserve fictional-demo labels.

This is an application-level Markdown procedure selected explicitly by the user,
not a native SDK skill registry, plugin, or separate agent.
